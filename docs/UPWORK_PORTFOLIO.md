## 3. Project description

Founders want to build with Claude Code, but have no safe foundation and Claude cannot see their marketing data. This demo build on sample data sets it up: Google sign-in, Google Ads and GA4 numbers synced into Postgres daily, a password protected staging site that deploys itself, and production deploys that wait for approval. Claude reads the data through a private MCP connector. Safeguards: read-only database role, token required, every call audited, writes blocked twice. 98 automated tests. Stack: Next.js, Postgres, MCP TypeScript SDK, GitHub Actions, AWS.
